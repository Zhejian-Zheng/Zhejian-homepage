# ASCII background and accents — 2026-11-06

Retains the existing near-black/cyan palette, IBM Plex Sans, JetBrains Mono and personal photographs. Adds a shell prompt, Sidecar ASCII sketch, photo corner marks and EOF footer accent.

The final background is a single viewport-sized Canvas 2D layer in the root layout, shared by all routes. Page backgrounds are transparent; solid cards and photographs remain above the effect. Pointer movement emits local displacement waves. No pause control, as explicitly requested. Reduced motion draws a static field; hidden tabs cancel animation; unmount removes listeners and the animation callback.

## Frame-rate correction

The first implementation explicitly throttled drawing to 24 FPS and rasterized text every frame. The final implementation follows requestAnimationFrame at the display refresh rate, caches glyphs in an atlas, precomputes cell data on resize, and rejects cells outside ripple bands before expensive calculations. Raster size stays at approximately 1.2 million pixels. Motion uses elapsed time so speed does not depend on refresh rate. There is no added dependency or WebGL context.

A temporary mocked runtime check exercised deterministic rendering, pointer displacement, 120 Hz callbacks, no per-frame text rasterization, raster limits, hidden-tab cancellation/resume, live reduced-motion preference changes and cleanup. This verifies behavior, not actual GPU FPS. No claim of measured 60/120 FPS or field CWV is made.

## Reproduce

Stop any development server sharing `.next`, then run from the repository:

```sh
npm run check
npm run typecheck
npm run dev
```

Check home, About, Blog, an article and Contact; scroll to the footer; move the mouse over open background; enable reduced motion and switch browser tabs. There should be no visible pause control. Use browser performance tooling on the target device to measure actual FPS.
