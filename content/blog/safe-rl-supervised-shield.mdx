<ArticleLanguage language="en">

This project puts a small idea to work: an RL agent that can ask a supervised model whether an action looks risky before it takes it. The experiment asks whether that filter makes learning faster, safer, or both, and what it costs.

The world is a 10 by 10 grid with a start state, a goal, and hazards. A baseline Q-learning agent learns from reward alone. The shielded version sends candidate actions through a classifier before it commits.

## Environment

Each state-action pair is described by position, action, and features derived from the environment. The reward is deliberately plain: positive at the goal, a small penalty for an ordinary step, a large penalty for a hazard.

That shaping makes the failure mode visible. An agent can learn to reach the goal and still have collected a lot of hazard violations on the way.

## Supervised Shield

The shield is a classifier trained on labeled state-action examples. The labels come from a multi-source BFS distance map grown outward from the hazards: immediate hazard, near hazard, farther risk, safe.

At each step the policy proposes an action and the classifier assigns it a risk level. If that level crosses the selected threshold, the agent picks among the safer candidates instead.

## Results Pattern

The threshold does most of the work. A loose threshold removes hazard violations without giving up much reward. A strict one makes the agent so conservative that success rate drops.

Both effects show up in the same experiment. A safety layer that only reports fewer violations says nothing about whether the task still gets done.

## Knowledge Points

- Q-learning keeps value estimation separate from the environment model, which makes it easy to drop into a grid-world experiment.
- A supervised model can carry domain knowledge into the loop as a reusable action filter.
- When the hazards are known, BFS distance gives a consistent way to label training data.
- A safety layer has to be judged on violations and task performance at the same time.
- False negatives matter most: one dangerous action that gets through can break the safety promise.
- The shield is policy guidance, not a replacement for the RL algorithm.
- Evaluation needs baseline reward, success rate, violations, and intervention counts side by side.

## Takeaway

Classical RL and supervised learning do different jobs here. The agent still learns the policy; the classifier draws a boundary around the actions it may consider. Most of the engineering sits in choosing that boundary, and the threshold is the first thing I would tune.

<ArticleLanguage language="zh">

这个项目把一个小想法跑了一遍：让 RL agent 在动手之前，先问监督模型这个动作危不危险。实验想知道这层过滤能不能让学习更快、更安全，又要付出什么。

环境是 10×10 的网格，有起点、目标和若干危险格。基准 Q-learning agent 只看奖励学习；加盾的版本会把候选动作先送进分类器，再决定执行哪一个。

## 实验环境

每个状态-动作对用位置、动作和环境衍生特征来描述。奖励函数写得很直白：到目标给正奖励，普通走一步有小惩罚，进危险格有大惩罚。

这样设计以后，失败模式就摆在明面上了：策略可以学会到达目标，但在探索过程中还是会积累很多次违规。

## 监督安全盾

安全盾是一个分类器，训练数据是带标注的状态-动作样本。标签来自以危险格为起点的多源 BFS 距离图，分成立即危险、附近危险、较远风险和安全四档。

每一步，Q-learning 策略先给出动作，分类器再判断这个动作的风险等级。等级超过当前阈值时，agent 就从更安全的候选动作里挑一个。

## 实验结论

阈值的位置比"要不要加盾"更影响结果。阈值放宽，危险违规能降下来，奖励也基本不掉；阈值太严，agent 会变得过于保守，成功率跟着下降。

两个方向在同一个实验里都能看到。只看违规次数下降，并不能说明任务还做不做得完。

## 知识点

- Q-learning 把价值估计和环境模型分开，放进网格世界实验里很直接。
- 监督模型可以把领域知识变成一个可复用的动作过滤器。
- 危险格已知时，BFS 距离是生成安全标签的实用办法。
- 安全层的效果要同时看违规次数和任务完成情况。
- 假阴性最要命：漏掉一个危险动作，安全承诺就破了。
- 安全盾是策略指导，不替代 RL 算法本身。
- 评估时把基线奖励、成功率、违规次数和干预次数放在一起看。

## 总结

经典 RL 和监督学习在这里各干各的活。策略仍然是 agent 自己学出来的，分类器只圈定它可以考虑的动作范围。真正要调的是这个范围有多紧，所以我第一个动的参数就是阈值。
